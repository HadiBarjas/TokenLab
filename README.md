# TokenLab 🚀
A fast, lightweight, and client-side JWT inspection tool built with Vanilla JavaScript and modern CSS architecture.

## ✨ Features
- **Real-Time Inspection:** Decodes Header, Payload, and Signature instantly without unnecessary clicks.
- **Zero External Dependencies:** Built purely with Vanilla JavaScript (`atob` and Base64URL parsing).
- **Dynamic Theme Switcher:** Smooth Dark / Light mode switching with optical balance, persisted in `localStorage`.
- **JSON Syntax Highlighting:** Custom colored JSON output representation for keys, values, strings, and numbers.
- **Micro-Interactions & UX:** Custom violet scrollbar, clipboard copy feedback, and animated toast alerts.

## 🛠 Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Variables, Grid, Glassmorphism, Custom Scrollbar)
- JavaScript (ES6+, DOM Manipulation, Clipboard API)
